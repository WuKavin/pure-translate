纯译 PureTranslate 设置

模型供应商

切换供应商不影响各供应商的已保存配置，随时来回切。翻译缓存按「供应商+模型」隔离。

仅保存在浏览器本地，请求直连 opencode.ai 并携带官方要求的会话请求头。⚠️ 官方（2026-09-09 起）明确 Go 面向 coding-agent 流量且有验证客户端白名单，翻译插件不在其中，使用存在账号风险，自行评估；零风险可选「本地 LM Studio」。

推荐：deepseek-v4-flash（额度高）/ glm-5.3-flash / mimo-v2.5（最省额度）。

LM Studio → Developer → Start Server 后使用，默认 http://localhost:1234/v1。无需 API Key；扩展已声明本地网络权限，LM Studio 的 CORS 开关无需打开。仅「已加载」的模型可用，本地模型较慢，建议把下方「每批段落数」调到 4~6。

任意 OpenAI 兼容端点（OpenRouter / Ollama http://localhost:11434/v1 / vLLM 等）。保存时会请求访问该地址的权限。

翻译

一次请求翻译的段落数。越大越省请求额度，越小越稳。

翻译角色（按站点类型自动切换提示词）

翻译是确定性任务，关闭思考可大幅提升输出速度、降低额度消耗。若个别模型不支持思考开关会自动降级重试。

预设参考沉浸式翻译样式库。单语模式不插入译文元素，始终回到原网页格式。

作用于 .pure-translate-target（译文元素），上限 8KB。参考预设可用 currentColor / color-mix 保证深浅色模式兼容。

自动识别会根据域名判断页面类型（GitHub/Stack Overflow → 技术文档，arXiv/.edu → 学术，Reddit/X → 社区等）。

排除规则

导出配置包含 API Key，请妥善保管文件。重装扩展或换机器后「导入配置」即可一键恢复。
